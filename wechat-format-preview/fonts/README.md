# 字体文件说明

请将华文楷体字体文件放置在此目录下。

## 支持的字体文件名

- `STKaiti.ttf` - 华文楷体常规
- `KaiTi.ttf` - 楷体
- `STKaiti.ttc` - 华文楷体合集

## 如何获取字体

### macOS 系统
字体通常位于: `/System/Library/Fonts/STKaiti.ttc`

你可以复制系统字体到这个目录：

```bash
cp /System/Library/Fonts/STKaiti.ttc ./fonts/STKaiti.ttf
```

### Windows 系统
字体通常位于: `C:\Windows\Fonts\simkai.ttf`

### 开源免费字体
也可以使用开源的楷体字体，如：
- [文泉驿微米黑](https://github.com/adobe-fonts/source-han-sans)
- [站酷快乐体](https://www.zcool.com.cn/special/zcoolfonts)

## 注意事项

1. 确保使用的字体拥有合法的商用授权
2. 个人使用建议使用系统自带字体
3. 商用请使用开源字体或购买商用授权
