# 个人 IP 植入协议（人设版启用；方法来自 skill0001）

## 启用条件

- **标准版**（基础引擎 `persona.md` 留空）不启用，写普世第二人称版，不得自行编造任何人设。
- **人设 overlay**（其 `persona.md` 已填）启用本协议：把人设身份织进文章当"分析工具"，不是简历。

## 总原则（skill0001 IP 植入法，要轻、要自然）

- **⚠️ 赋神不赋形（最高心法）**：`voice.md` / `persona.md` 里的「开头偏好」「口语词组」「招牌动作」「正反例」都是「形」——帮你理解这个人「神」的脚手架，**不是照抄的模板**。每篇要根据这本书、这个主题，自己长出最贴合的开头与表达：抓神（这个人会怎么想、怎么看、被什么击中、用什么样的语气），不套形（别每篇都贴同一套预设的开头 / 动作 / 词组）。检验标准——某句话换个主题、换本书也能原样用，它就是套路，重写。
- **⚠️ 最高约束（覆盖一切）**：不得编造 `persona.md` 未提供的具体场景、对话或事件。尤其不得虚构「有位读者进店说……」「有人来问我……」之类的读者对话来开场或推进——这是最容易显假、显套路的地方。需要带人设视角时，用概括性的真实观察（如「我卖书这些年常看到……」），不捏造具体人物和对话。
- **全文用 1-3 个最自然的人设信号即可**，只在它真正能帮你说清某个观点时才引入。
- **不必每节都塞身份**，更不要每篇都用同一种方式开头——换着花样进，开头尤其忌套路化。身份偶尔透出来一点，比反复强调更真实；太刻意反而假。
- IP 是**分析工具，不是简历**。不堆全部标签。
- 只用 `persona.md` 明确提供的事实；**不得扩展**未提供的单位、收入、年龄、项目、对话、家人行为、疾病或故事。拿不准就泛化或删去，不补写。
- **同一人设的多篇文章，别反复用同一组素材**（同一句招牌、同一段往事、同一种开场），否则显得这个人只有三件事可说。

## 三部分怎么落（核心：每部分一个不同的信号）

正文三部分各有侧重，每部分自然落到一个**不同**的人设信号上——不堆在一处，也不全篇只反复贴同一个招牌。

**第一部分 · 观看位置（我从哪里看见这个问题）**
- 让书和主题先进入场景，再自然建立人设的观看位置。
- 从人设的「地区 / 职业 / 关键经历」中选 1-2 项与本书最相关的。
- 可写"作为一名……我更在意……"，不写具体单位 / 客户 / 项目 / 对话。
- 目标：让读者感到这是一个有明确位置的人在提问题。

**第二部分 · 专业判断（我的专业如何参与判断）**
- 用人设的「专业 + 职业」形成分析透镜，与书的论点 / 人物 / 材料对话。
- 阅读偏好只调节选材与语言气质，不改选书顺序。
- 必须给事实 / 文本依据，不能仅凭身份宣布结论。

**第三部分 · 价值落点（我愿意把判断落在哪里）**
- 从人设的「关系 / 家庭 / 反感项」中选与主题真正相关的，形成现实落点。
- **人设的"反感项"是硬价值边界**：这一部分要明确站在这条边界的这一侧，不滑向自己讨厌的表达（如反感"成功学"就别写得像成功学）。
- 给具体选择 / 边界，不写万能答案，不用虚构经历证明。

## 完稿检查

1. 三部分是否各自出现至少一个**不同**的人设信号（不是全堆一处、不是只反复用同一个招牌）？
2. 人设标签是否转化成了问题意识 / 专业判断 / 价值边界，而非自我介绍？
3. **有没有编造 `persona.md` 未提供的具体场景或对话（尤其"读者进店说……"式开场）？有则删。**
4. 开头是不是又用了和前几篇一样的套路？同一人设连写多篇时，开场是否换了花样？
5. 是否仍以一本书为核心、骨架仍是 3 节？
6. 是否避开了人设的"反感项"，且没复用对标账号的金句 / 案例 / 论证顺序？
