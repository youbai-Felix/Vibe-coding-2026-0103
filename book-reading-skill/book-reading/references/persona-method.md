# 人设写作方法论（所有人设 overlay 共用，人设无关）

基础引擎提供骨架（选书 / 3 节结构 / 字数 / 校验 / 封面），本文件提供"人设文章怎么写"的通用方法。各 overlay 的 `voice.md` 只补充该人设**独有**的声音与 IP 角度。

## 招牌动作（每篇自然用 3-5 个）

1. **开头建立观看位置**（见 `ip-integration.md` 第一部分）：一个有具体位置的人在提问题，不是无来源的通用观点。各人设的"怎么建立"见各自 voice.md。
2. **念一句书里原文**（引用块 `>`）+ 一句**真实、具体**的私人反应。反应必须属实——没真抄别写「抄了」，没愣别写「愣了」；每篇不重复套同一动作（详见禁区）。
3. **一个被戳中的小细节**：具体画面，不讲全书。
4. **坦白一处没懂 / 读得慢 / 不认同**：真诚 > 全盘叫好。
5. **`# 写在最后` + 完整结尾段**：结尾用一级标题 `# 写在最后`（与节标题同级），下面是**一段完整的话**（跟正文段落长度相当，不是只留一句），末尾自然升华。**段内**不推销、不出现"读 / 翻 / 这本书 / 值得"等推荐字眼，不荐别的书（段末的 `👇👇` 导流推荐语是独立一行，不受此限）。

## 爆款杠杆（保留人设声音的前提下补冲击力）

1. **标题加钩子**：保持该人设语气，加反差 / 悬念 / 痛点 / 情绪，让人想点开。不要纯标题党、不"改变人生 / 必读"。
   - **标题不必含书名**（每次都放书名显得刻意）；能吸引人点进去 + 贴合文章主题即可。书名可以只出现在正文和封面里。
2. **每篇留一处真情绪，但收着写**：允许其中一处"突然真诚"有冲击力，但靠**具体可感的人事物**自然打动，**不用夸张的情绪词/反应去渲染**（别「反胃」「笑出声」「彻底垮了」式用力）。克制比砸更可信。
3. **选题找大众共鸣切口**：孤独 / 成长 / 关系 / 焦虑 / 得失，别太私人小众。

## 推荐要隐晦（这是带货号，不是安利号）

最终目的：让读者读完，**意犹未尽，想亲自去书里游历一番**，自己点底部链接买这本书。买书不需要明着引导，明着推反而招烦、显得功利。

- **全文只围绕这一本书**。绝不推荐、提及别的书。
- **不写明着推销的话**：禁用「这本你得看看 / 快去买 / 必读 / 强烈推荐 / 改变人生」。底部链接负责转化，文章只负责让人心痒。
- **推荐靠"打动"**：写作者自己被这本书触动 / 改变 / 记住的反应，读者自然想读。
- **「写在最后」段内零推荐字句**（连"值得读""这本书"都不要，只留升华与鼓励）。段末另起一行的导流推荐语 `👇👇读《书名》：金句` 不算段内违规（见 structure-policy.md，默认加）。
- **只取书中一个切口，别把书讲尽**：读者要觉得"书里还有好多没写出来的"，才有动力去翻；讲尽了，读者就不必看了。
- **留"书里还有"的钩子**：可点一句"另外几支更锋利，书里还藏着""这只是其中一段"，让读者自己生出想去翻的念头，但不发"去翻 / 去看 / 值得读"这类硬指令。
- **把书写成能走进去的世界，不是干货清单**：让读者觉得去书里是"逛"、是游历，而不是已经读完摘要。

## 禁区（最易出 AI 味 / 出戏）

- 不装专家、不端着、不爹味说教（思辨型人设可下判断，但不下廉价绝对结论）。
- 不堆「必读 / 改变人生 / 受益终生」。
- 不把读书写得很苦很神圣；不故弄玄虚，说人话。
- **绝不推荐别的书**；**绝不明着推销**。
- 引用书里原文要诚实：是原文就标注抄下来的，别把私货包装成原文。
- 不编造人设未提供的具体经历 / 对话 / 单位 / 家人行为（见 `ip-integration.md` 事实边界）。
- **禁止不知所云、模糊不清的判断**：不写「是个狠的」「收得住」「没把自己弄丢」这类空泛金句；每个判断具体、清晰、可被理解。
- **不编造写作者的反应动作**（抄了 / 愣了 / 做了某事 / 贴在某处）来凑「隐晦推荐」——反应必须真实且具体，不许每篇套路化套用。
