# 洞见 内容机制档案

- 内容置信度：high（基于多篇真实完整正文蒸馏）
- 核心定位：以「一本书」切入「一个普遍人生困境」，治愈系人生智慧
- 目标读者：被生活/工作/情感困扰、需要被安慰和点醒的普通人
- 本档案只迁移抽象机制，不复用任何具体故事、人物、比喻、金句、论证顺序。

## 标题公式

[权威背书或热点] + [一本书/一个道理] + [读者痛点]，用「才明白/就会/值得」等钩子。
情绪前置、留悬念、直击痛点，但不做纯标题党。

## 整体骨架（高度固定，这是灵魂）

1. **开头钩子**（三选一）：一个反问 / 一句名人名言 / 一个热点事件或权威背书。
2. **点题段**：2-3 个极短段落，亮出全文要解决的「人生痛点」。
3. **主体 3 节**（固定），编号 01/02/03，每节结构完全一致：
   - 一句加粗「金句小标题」（本节的人生道理）
   - 讲书中一个人物/情节的故事（叙事，娓娓道来）
   - 由书内延伸到现实 / 其他名人其他书（共鸣放大）
   - 一段升华，落到「你」身上
4. **收尾**：`# 写在最后` 标记 + 一段完整收束的话（末尾自然落到一句全书核心金句 + 温暖鼓励/行动号召）。

## 句子与节奏

- 段落极短：绝大多数段落只有 1-2 句，一句一段很常见 → 大量留白、阅读无压力。
- 短句为主，长句少；节奏舒缓如说话。
- 高频转折制造感悟：「但 / 可 / 然而 / 殊不知 / 只可惜」。
- 第二人称「你」精准投放，像朋友对话：在落到读者处境、请求共鸣或落到「你」的行动时用，不必每句都塞，更不凑次数。

## 金句机制（核心竞争力）

- 每节开头一句加粗金句；每节结尾一句可摘抄金句。
- 全文金句密度极高，几乎每段都有可传播句。
- 金句类型：人生规律总结 + 反差对照（「不是 A，而是 B」）。
- **金句必须准确清晰**：禁为「金句感」说空泛模糊的话（「是个狠的」「收得住」式）——表意清楚优先于漂亮。宁可一句明白话，不要一句漂亮的废话。

## 引用机制

- 名人名言密集（季羡林、罗翔、白岩松、麦家、余华、毛姆、马尔克斯…），起权威背书与共鸣放大作用。
- 书中原文用引用块（`>`）呈现。
- 排比引用：「读《活着》…；读《平凡的世界》…；读《老人与海》…」。

## 情绪温度

- 治愈、温暖、鼓励、安慰（软慰系）。
- 不批判、不犀利、不说教、不贩卖焦虑。
- 落点永远是积极的：接纳、释然、向前、靠自己。
- **克制，不刻意用力**：不堆夸张情绪词和反应去逼读者感动（禁「反胃」「笑出声」「愣了好久」「彻底垮了」式用力）；情绪点到为止，靠事实和细节自己说话。

## 选题逻辑

- 一本书 ↔ 一个普遍人生痛点：孤独、选择、偏见、苦难、聚散、运气、心态。
- 书只是「药引」，真正写的是读者自己的人生。

## 原创与事实边界

- 不得拼接传闻、伪造内幕、复制热点稿叙事顺序、把立场写成事实。
- 不冒充「洞见」作者或机构，不声称作品得到其授权、审核或推荐。
- 不虚构书中情节、名人语录、研究结论。
- 对拿不准的事实泛化处理或删去；找不到可靠依据时不补写。
