# 骨架政策（固定 3 节）

## 总原则

- 正文主体 **固定 3 节**（三段式）。
- 人设可在各自 voice.md 的「结构偏好」里写节奏差异，但节数统一 3 节。
- 每节结构必须一致：金句小标题 → 核心论据 → 现实延伸 → 升华到「你」（核心论据**优先用个人真实素材**，书中情节仅作引子）。
- **每篇必须围绕一本书**：不论输入是不是书评，都要按 SKILL.md 选书规则选一本最合适的书做解读，不得写成无书的泛泛而谈。
- **降复述、提原创（2026-08-13 游白定，规避「低创作度/搬运」判定）**：书中情节只作引子（**全文 ≤ 300 字**），主体是个人真实素材 + 现实观察。每篇必须有「只有作者本人才会写」的内容——这是平台判原创度的核心信号。

## 每节内部结构

1. **加粗金句小标题**：一句人生道理，以**正面判断**为主（直接说出道理，如「每一次违心的答应，都是从自己身上割一块肉」）。「不是 A，而是 B」类反差句式属翻案腔族，**全文（含小标题）合计 ≤ 1 处**（`check_originality.py` 硬卡），不要每个小标题都用。用 `**加粗**` 呈现。
2. **核心论据**（约 150-200 字）：本节支撑，三选一：
   - **① 个人真实素材（优先）**：来自素材池的一条「你」的真实经历/观察，做主体。**每篇至少 1 节用它做主体**——这是规避「低价值 AIGC / 搬运」判定的关键。
   - **② 书中情节（作引子）**：原书人物/情节，只点不展开，**单节 ≤ 100 字、全文 ≤ 300 字**（降复述、避搬运判定）。一本书每节用不同人物/情节，不重复。
   - **③ 现实观察/现象**：由生活现象切入放大共鸣。
3. **现实延伸**（约 60-100 字）：由书内延伸到现实生活，或引一个名人/他书的例子放大共鸣。
4. **升华落到「你」**（约 60-100 字）：用第二人称「你」收束，给出接纳/释然/向前/靠自己的积极落点，结尾尽量是一句可摘抄金句。

## 三种必备 Markdown 样式（缺一不可，`check_style.py` 硬校验）

- **标题**：全文统一一级标题 `#`——文章总标题 + 每节编号标题（# 01/02/03）+ `# 写在最后`，不用 ## / ###。
- **加粗**：每节开头的金句小标题用 `**加粗**`，全文 ≥ 3 处。
- **引用**：书中原文、名人名言用 `>` 引用块呈现，全文 ≥ 1 处。

## 开头（钩子 + 点题，共约 100-150 字）

- 钩子三选一：一个反问 / 一句名人名言 / 一个热点事件或权威背书。
- 接 2-3 个极短段落（多数一句一段），亮出本文要解决的人生痛点，并自然带出要讲的那本书。

## 结尾（`# 写在最后` + 完整结尾段，共约 100-150 字）

- 用**一级标题** `# 写在最后`（与节标题同级，不用加粗）。
- 下面是**一段完整的话**（跟正文段落长度相当，不是只留一句升华），层层收束到末尾的升华。
- 不推销、不荐别的书（推荐语荐的是本书，不是别的书）。
- 推荐语（默认加）：写在最后那段之后，全文最末另起一行 `👇👇读《书名》：金句`（一句戳人的核心金句，导流收尾）。

## 篇幅分配（净字数，目标 1000-1200；下表上下限任意组合都落在目标区间内）

| 部分 | 字数 |
|---|---|
| 开头（钩子+点题） | 110-130 |
| 第 1 节 | 260-310 |
| 第 2 节 | 260-310 |
| 第 3 节 | 260-310 |
| 结尾（写在最后+金句+鼓励） | 110-130 |
| **合计（3 节）** | **1000-1190** |
