# 禁用词与套话表（降 AI 味）

本表是「减法」——把 AI 高频踩雷的空洞表达刮掉，剩下的才有洞见的活人感。
`scripts/check_style.py` 会自动扫描「绝对禁用」项，命中即判不通过。

## 绝对禁用（命中即 fail）

**教科书 / 报告套话**
- 综上所述 / 总的来说 / 总而言之
- 值得一提的是 / 值得注意的是
- 不难发现 / 不难看出
- 毋庸置疑 / 不可否认 / 众所周知
- 让我们来看看 / 接下来让我们 / 下面我们来看

**宏大叙事开头**
- 在这个快节奏的时代 / 在这个××的时代
- 随着社会的发展 / 随着时代的发展 / 随着××的进步
- 当今社会 / 现今社会

**书面化填充**
- 说白了
- 换句话说
- 本质上 / 从本质上讲
- 这意味着 / 意味着什么呢

**空洞升华**
- 这不禁让人陷入沉思 / 这不禁让人××
- 或许这就是人生 / 这就是人生的意义

**伪深度隐喻金句**（为深刻而深刻的抽象隐喻——听起来唬人，经不起一句追问）
- "把命分了一点给他们" / "交出了半条命" / "把灵魂××" / "把心剜了一块" — 命怎么"分"？分了之后呢？用无法验证的抽象隐喻制造震撼，代替真实可感知的描述。

**强行接地气 / AI 腔调**（AI 以为这样写很口语，实际一读就假）
- "最×的地方" / "最×的一点"（如"最狠的地方""最戳我的一点"）— AI 公式化强调
- 栽过 / 栽坑 / 正在栽 — 强行接地气，反而暴露
- 崩了 / 破防了 / 绷不住了 / 裂开了 — 网络流行语式情绪概括，AI 以为有画面，实际偷懒一笔带过（是哭、是瘫坐、是摔东西？给具体，别用"崩了"糊弄）
- "今天想跟你聊" / "今天想分享" / "今天聊聊" — AI 开场套话

**禁用符号**
- 破折号（—— / —）：用来做停顿、补充、转折，是文艺腔和 AI 腔的标志；该断句就用逗号或句号另起一句。`check_style.py` 计数 U+2014，命中即 fail。**豁免**：首个 H1 总标题（照搬原标题）与引用块行（书中原文照录可含破折号）。

## 限频（不禁用，但 AI 爱滥用到油腻）

- 「正如一句话所说」——空洞。要引用就给具体出处（季羡林说 / 书中写道 / 余华写过），别用「正如一句话所说」糊弄。每篇 ≤ 3 次（`check_style.py` 软警告）。

## 翻案腔族（不是 A 而是 B 等 11 种变形，全文 ≤ 1，`check_originality.py` 硬卡）

- 「不是 A，而是 B」「并非…而是」「不在于…而在于」「与其说…不如说」「表面…实际」「看似…实则」「你以为…其实」「回头才发现」「答案恰恰相反」「不重要…重要的(是/在于)」「真正值钱」——这是微信 AIGC 检测的头号特征句式，**全文（含各节加粗小标题）合计 ≤ 1 处**，超出禁止交付。首个 H1 总标题照搬原文豁免。金句小标题以正面判断为主（详见 structure-policy.md）。

## 允许（这些是洞见的合法手法，别误伤）

- 第二人称反问开头（「你有没有过……」）——合法钩子。
- 名人名言引用（带具体人名）——合法，且要密集。
- 「但 / 可 / 然而 / 殊不知 / 只可惜」转折——合法，这是洞见节奏的来源。
- 温暖收尾「愿你……」——合法，只要落点具体、不空洞。

> 注：本表的「绝对禁用」清单与 `scripts/check_style.py` 中的 `BANNED` 列表必须保持同步，改一处改两处。
